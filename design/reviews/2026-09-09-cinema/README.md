# Paper Robots screening homepage — September 9

San rejected the preceding homepages as conventional blogs. This version uses
actual moving film artwork as the opening environment, a two-film selector and
an in-page screening dialog. The collection uses large painted film stills;
the essay has its own illustrated invitation. Navigation, complete reading,
film scripts, sources, chapters and captions remain available.

`homepage-*` shows the active preview at desktop and phone widths.
`reading-edition-*` checks that the full article layout is preserved.
`browser-checks.json` records 24 route/viewport checks plus the film selector,
preview pause, screening/Escape behavior, no-JS links and reduced-motion fallback.
Run `npm run build`, `npm run check`, then `node scripts/check-browser.mjs` against
the local preview. This folder records local production builds. The work awaits
San's assessment; no award or visitor validation is claimed.
